ODHT - 升级说明

感谢使用 ODHT（Online Dictionary Helper for Translators）。如需完整文档，请访问 项目主页

v1.1.0 新增内容
  1. 翻译方向可配置：Source Language / Target Language 下拉框，支持 16 种语言互译
  2. 翻译结果缓存：同一句子不重复调用 API，节省额度
  3. 翻译状态提示：弹窗显示 ⏳ 翻译中 → 翻译结果 → ⚠ 失败原因
  4. 翻译结果可编辑：直接在弹窗内修改翻译文本，改完再存入 Anki
  5. 预设 Anki 模板：新增 ODHT.apkg，导入即包含 autotranslation 字段和卡片模板
v1.0.0 新增内容
  1. Manifest V3 迁移，兼容最新 Chrome
  2. LLM 自动翻译：火山引擎豆包翻译模型，弹窗内显示原句翻译
  3. 选区扩展：◀/▶ 按钮逐词扩展选区，方便查询短语
  4. 智能短语检测：自动检测相邻文本是否构成已知词典短语
  5. 修复当访问本地 HTML 时弹窗界面 UI 混乱的问题

ODHT - Upgrade Notes

Thanks for using ODHT (Online Dictionary Helper for Translators). For full documentation, visit Project Home

v1.1.0 What's New
  1. Configurable translation direction: Source/Target language dropdowns, 16 languages supported
  2. Translation cache: same sentence won't trigger duplicate API calls
  3. Translation status indicator: ⏳ Translating... → result → ⚠ error message
  4. Editable translation: click to modify the translation in popup before saving to Anki
  5. Preset Anki template: new ODHT.apkg with autotranslation field and Back Template included
v1.0.0 What's New
  1. Manifest V3 migration, compatible with latest Chrome
  2. LLM auto-translation via Volcano Engine Doubao API
  3. Selection expand: ◀/▶ buttons to grow selection word by word for phrase lookup
  4. Smart phrase detection: auto-suggest known dictionary phrases from adjacent text
  5. Fix popup UI issue when accessing local HTML files
